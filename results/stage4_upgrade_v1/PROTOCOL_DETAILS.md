# Frozen campaign protocol and explicit qualifications

- New run start/deadline are in experiment_plan.json. Previous Stage4's 90-minute timer is never used.
- Protected old inputs are the physical files present at this run's start, including uncommitted historical work. Git cleanliness is not assumed. Initial 46 tests were rerun.
- Primary local ADAPT pool contains two-site YZ/ZY and bounded consecutive YXZ/ZXY strings. Three-point two-site-only and maximum-gradient ablations are separate. Completeness is not established. Maximum resource-normalized eligible gradient below 1e-5, energy stagnation below1e-8, or budget exhaustion stops growth; no ED stopping criterion.
- References and every compiled gate are explicit. exp(-i theta P) is basis changes, parity CNOT ladder, RZ(2 theta), inverse ladder/basis. Every CNOT is charged and noisy on its target. Basis rotations are ideal under the specified model. The three-site periodic supports' sorted ladder still uses only direct ring NN/NNN edges.
- All generators commute with global X. Individual local parameters can break translation symmetry; no state projection repairs this. C(r) is a site average, and ED fidelity supplies an additional acceptance check.
- Main selection minimizes CNOT count within N*1e-4 of the lowest candidate energy. B4 minimizes noisy energy at p=.01 among two exactly equivalent compiled directions and pays for that extra evaluation. Preparation masks are applied only in analysis; ED does not select B4. No HVA fallback is counted as an adaptive success.
- 18 development points,6 validation points,48 held-out half-step coordinates and420 historical-map coordinates were listed before adaptation. The historical map is descriptive, never blind validation. Full-grid seeds differ in number from development; this is frozen and is not a three-start success claim.
- B0 matched comparisons reuse old Stage3 numerical archives unchanged. A new three-point HVA search ablation caps each run's energy-gradient calls using its paired adaptive run's actual call count; SciPy may finish a final line search beyond maxfun, and actual calls are saved. This auxiliary budget comparison is separate from the formal historical B0 grid.
- Checkpoints store exact reported budget-reachable gates; odd GHZ reference parity means caps such as32 may use31 CNOTs. No arbitrary filling gates are added. The fixed-short B2 pilot uses8 YZ rotations plus7 reference CNOTs, i.e.23 total.
- N12 memory was measured with a full density matrix and all working arrays: peak ~1.84GiB in the31-CNOT pilot. Representative density runs are serialized separately from large MPS jobs. All three p are exact-density simulations, not shot samples or amplitude-averaged trajectories. A separate N8 trajectory test validates the fallback implementation.
- Statistical measurement experiments use multinomial sufficient statistics of joint bitstrings, equivalent to recording every bitstring; the same draw supplies all observables in each basis. Thirty SV settings include Z, X, and each YY pair with X elsewhere. ZZ*P=-YY*X_rest. The denominator and resource allocation are saved. Reported measurement rotation count describes the compiled settings; CNOT-weighted shots describe executions.
- ZNE uses actual complete circuit folds, including reference gates. Linear weights are13/12,1/3,-5/12; Richardson weights15/8,-5/4,3/8. Neither fits p0 or ED. Outputs are not clipped to a physically convenient range.
- Squared Uhlmann uses the trace norm of sqrt(rho)sqrt(sigma). Negative/roundoff density eigenvalues below1e-14 are clipped in the square root; substantial negative values error. The initial sandwich-eigenvalue cutoff failed self-fidelity and was replaced before diagnostic experiments. Regression logs retain both runs.
- Main D1/D3 labels are observable resemblance, not rigorous phases. D3 normalization/PCA/clusters/mapping are trained only on clean development. Simulation access costs for D2 are explicit. Raw old classifier uses three features only. Fully mixed is degraded rather than high-field paramagnetic.
- Grid derivative support intervals and repeated-shot quantiles are distinct. No smoothing/interpolation produces additional physical resolution. Fixed-structure anchors h=.5,1 are descriptive branch controls, not labels or deployable reference selectors.
- Floating evidence is separate OBC classical MPS; N8/N12 OBC/PBC bridge data accompany it. No U(1) Sz conservation. Pauli operators are checked by full small-N matrices. chi and N convergence, both initial states, fit windows, raw/connected correlations and entropy jointly qualify any claim. Evidence-grading thresholds are transparently post-computation review criteria, not model selection parameters or hidden tuning of held-out labels.
- Independent Trotter uses signed RX(-h*dt) half-field blocks and RZ(2*c*dt) interactions, c=-1 or+kappa. Common-time data are accumulated incrementally. Fixed product-state preparation adds no CNOT. No frequency/thermodynamic claim follows from t<=2.

Resource updates are explicit in resource_amendment_v1.json and orchestration_amendment_v1.json. Actual process RSS inspection exposed trajectory duplication in orchestration indices; three map workers were interrupted and resumed against unchanged hashed optimization caches using compact indices. The full raw records and original compressed index snapshots are retained. NumPy is linked to Accelerate; OMP/OpenBLAS limits were requested, and observed process CPU usage was approximately one core per worker. Do not describe the N12 pilot peak as the full campaign peak: later N12 density checks reached approximately2.24GiB, with final peak logged by /usr/bin/time and resource.getrusage.

A concrete selector limitation is visible at frozen held-out (kappa,h)=(.975,.15): the energy-tolerance resource rule selects GHZ-reference31 CNOTs with F_ED=0.5000096 although an antiphase-reference32-CNOT candidate has F_ED=0.9999880. Both pass the observable/energy criteria. The selected state retains global-X parity but has translation overlap approximately0, while the ED ground state has momentum0. The low energy gap explains why the frozen energy tolerance cannot certify the target pure state. This remains a primary-method failure. An explicitly labeled ED-oracle table is diagnostic only, not held-out tuning. D3 also shares D1's degraded-control veto; the methods have different mechanisms, but are not statistically independent.

Search-cost audit: the frozen solver's raw `pool_gradient_evaluations` counter counts appended rounds and assigns a spurious round to fixed B2. It omits the final zero-gradient screening round. `upgrade_accounting.py` corrects these purely accounting issues in all_optimization_runs.csv: fixed B2 has no pool screening; gradient-stop ADAPT includes one final round. Raw solver records remain unchanged for provenance. Prospective parameter-shift costs include the two measurement bases for each energy; actual hardware executions remain zero. This correction does not change any prepared state or selector.
