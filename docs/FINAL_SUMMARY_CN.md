# 公开作品摘要

Team hamster：Shupei Zhang、Yangxin Zhou、Michael Li、Kathy Chen。

本项目研究低 CNOT 制态与等 CNOT-shots 误差缓解。实验表明，两者可以改善可观测量重建；相特征和边界恢复则需要单独评估。正式统计只使用 active 索引中的记录。六条 B3 窗口均已执行，其中 κ=.5 的参考未通过预先冻结的峰筛选规则，因此不输出相界位置。最终证据包含 0 个获支持的浮动相样本，实验没有建立连续浮动相区间。

仓库包含完整实现、原始计数、失败记录、独立参考和大尺寸证据。超过普通 Git 文件大小限制的深层数据列在 optional_assets.json 中。队伍已确认 submitted: true，dashboard_status: draft；提交记录已保存，后台状态为 Draft。
