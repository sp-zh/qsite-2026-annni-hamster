# Data tiers

## Main submission (self-contained)

- All420 B3 map coordinates: numeric ED/circuit/noisy observables, quality and detector outputs, exact gate tables and chosen parameters; raw and equal-shots ZNE panels are distinct.
- B0 matched420-point observations and frozen selected parameter archives; B3 original noise archives and comparison rows. The max-correlation-error table is rechecked from observables against ED.
- Followup active A/B union:2718 original record/count files, all32 repeats and covariances, associated probabilities and literal circuit inputs,102 window coordinates and45 resource coordinates with overlap. Formal metrics are active-index only.
- Full six-window numeric curves, repeated samples, feature matches, audit flags and branch controls; no dropped endpoint or failed-reference-window records.
- Numerical confirmation/N12 rows, reference tables, floating interval/fit records, complete small dynamics observable files, scientific implementations and original lock files.
- Notebook/report/slides, reproducible statistics, verification entries, source and payload hashes.

The main repository contains the full formal count and window evidence, including failed and negative cases.

## Published deep evidence and optional Release assets

Deep original map/low-field/confirmation/N12 measurement counts and probability records; all648 valid excluded followup attempts; candidate/selected-state checkpoints and branch evidence; MPS observations and convergence records with five key actual MPS checkpoints. The repository includes the deep Stage5/Stage6 count and probability records. Seventeen large assets are published in Release v1.0.0; provenance/optional_assets.json records their paths and hashes. Main Run All uses bundled inputs.

## Original local research archive (not repackaged)

The complete Stage5/Stage6 multi-GB archives, all earlier intermediates/optimization traces/dense states, additional MPS state checkpoints, and historical generated artifacts remain in the original workspace. Historical source references identify their original locations; runtime release adapters resolve only bundled declared inputs and fail if one is missing. They never silently fetch an old source.
