# Data tiers

## Main submission (self-contained)

- All420 B3 map coordinates: numeric ED/circuit/noisy observables, quality and detector outputs, exact gate tables and chosen parameters; raw and equal-shots ZNE panels are distinct.
- B0 matched420-point observations and frozen selected parameter archives; B3 original noise archives and comparison rows. The max-correlation-error table is rechecked from observables against ED.
- Followup active A/B union:2718 original record/count files, all32 repeats and covariances, associated probabilities and literal circuit inputs,102 window coordinates and45 resource coordinates with overlap. Formal metrics are active-index only.
- Full six-window numeric curves, repeated samples, feature matches, audit flags and branch controls; no dropped endpoint or unresolved-window records.
- Numerical confirmation/N12 rows, reference tables, floating interval/fit records, complete small dynamics observable files, scientific implementations and original lock files.
- Notebook/report/slides, reproducible statistics, verification entries, source and payload hashes.

This closure slightly exceeds the provisional300MiB main-archive target. The target is not an official limit. Complete formal counts and window evidence were retained rather than deleting failed/negative cases to hit it.

## Optional supplementary_data.zip (local; not hosted)

Deep original map/low-field/confirmation/N12 measurement counts and probability records; all648 valid excluded followup attempts; candidate/selected-state checkpoints and branch evidence; MPS observations and convergence records with five key actual MPS checkpoints. Its manifest assigns original paths, hashes and inclusion reasons. Original scientific metadata are not rewritten. Main Run All does not use the supplement.

## Original local research archive (not repackaged)

The complete Stage5/Stage6 multi-GB archives, all earlier intermediates/optimization traces/dense states, additional MPS state checkpoints, and historical generated artifacts remain in the original workspace. Source references in archived records may point there for optional deeper research; runtime release adapters resolve only bundled declared inputs and fail if one is missing. They never silently fetch an old source.
